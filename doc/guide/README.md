# Namica 用户指南

Namica 是使用 C++20 开发的个人游戏引擎原型，目前支持 Windows。本指南介绍已经可以使用的模块，帮助你从源码构建、调用基础能力和运行示例。

项目仍处于早期阶段。窗口、渲染和贪吃蛇主要位于实验代码中；编辑器只有启动入口，完整的场景制作与发布流程尚未提供。

## 从这里开始

首次使用请先阅读[构建与接入](GettingStarted.md)，然后选择需要的模块：

| 想做什么 | 指南 | 对应模块 |
| --- | --- | --- |
| 使用基础类型、取得日期时间文本 | [基础类型与时间](Core.md) | core |
| 输出日志、使用便捷宏、设置等级和显示格式 | [日志](Logging.md) | log / Log、Logger、ConsoleSink |
| 定位资源目录、读取文本和图片 | [文件与图片](FileSystem.md) | io |
| 使用向量、变换矩阵和四元数 | [数学](Math.md) | math |
| 了解应用入口、运行渲染和游戏实验 | [应用入口与示例](Examples.md) | app / editor / playground |

各篇按使用场景说明接口、示例和必要限制；完整声明可从文中的头文件链接查看。文档随已实现功能和使用方式更新。

本文档中的路径以仓库根目录 `Namica/` 为基准，命令默认在根目录执行。已有学习记录与项目日记保留在 `doc/` 的其他目录。
